# SafeWork — Interactive Health & Safety Training System

SafeWork is an interactive Health & Safety training prototype developed by **SafeTech Solutions** for the **CET257 Enterprise Project — Assignment 1, Task A7**.

The prototype is designed for a logistics and warehousing environment within the automotive sector. It demonstrates role-based training, interactive workplace scenarios, assessments, progress tracking, certification, supervision and administration.

---

## A7 Prototype Scope

The A7 prototype demonstrates the core SafeWork workflow:

**Assign Training → Complete Training → Identify Hazards → Take Quiz → Receive Result → Generate Certificate → Monitor Progress**

### User Roles

- **Worker** — completes assigned training and assessments.
- **Supervisor** — manages workers, assigns training, monitors progress and sends reminders.
- **Administrator** — manages users, training modules, reports, reminders and certificates.
