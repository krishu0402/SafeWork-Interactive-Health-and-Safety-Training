# SafeWork – Assessment Evidence Map

This release supports the prototype and demonstration part of the enterprise project submission. The assessment brief should be submitted with the team's own reports, evidence and presentation materials.

| Assessment area | Evidence included or supported |
|---|---|
| B1 High-level design | Role workflows, worker/supervisor/admin journeys, database schema, testing notes and user guide in this package |
| B2 Promotional website | Public SafeWork landing page with corporate identity, mission, service features and sign-in call to action |
| B3 Client interactions | Add the team's own meeting minutes, emails, feedback and evaluation report; these cannot be generated truthfully without the team's evidence |
| B4 Application security | Authentication, role checks, bcrypt password hashing, Helmet, HTTP-only sessions, input validation and audit logging; see `docs/SECURITY.md` |
| B5 Self and peer assessment | Complete the official Canvas sheets using the team's real contribution percentages |
| B6 Prototype and demonstration | Runnable Express/SQLite application, setup instructions, role-based demo accounts and demonstration flow |
| B7 Team poster | Create the required A1 landscape poster using the team's real team details and screenshots |

Do not claim that B3, B5 or B7 are completed unless the team has added its own evidence and official documents.
