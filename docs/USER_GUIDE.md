# SafeWork User Guide

## Worker

1. Open the website and sign in with the private credentials file.
2. Review the dashboard cards for progress, completed modules, outstanding work and overdue items.
3. Select **Start** or **Retry** for an assigned module.
4. Answer every question and submit the knowledge check.
5. Passed modules show a certificate action. The certificate opens in a printable browser window.
6. Use the sidebar to switch between Dashboard, My training and Certificates.
7. Use **Log out** to end the session.

## Supervisor

1. Sign in using the supervisor account.
2. Review team members, completed training, overdue work and completion rate.
3. Open **Manage team** to add or edit worker accounts.
4. Use **Assign training** to select a worker, module and due date.
5. Open **Reports** and export the current report as CSV.

## Administrator

1. Sign in using the administrator account.
2. Review total users, active modules, workers and training records.
3. Manage users and review their role, department and active status.
4. Create additional training modules and set a pass mark.
5. Review or export training reports.
